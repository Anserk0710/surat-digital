# Surat Digital

Monorepo Surat Digital.

## Repository

- `apps/web` — frontend
- `apps/api` — API/backend
- `apps/document-worker` — document processing worker
- `packages/*` — shared packages
- `apps/api/prisma` — Prisma schema/migrations
- `supabase` — Supabase config dan RLS tests
- `docs` — project documentation
- `infra` — deployment/infrastructure configuration

## Requirements

- Node.js 26.13.0
- npm 12.2.2

## Install

```bash
npm ci
```
